# İrem Özbilgin — Portfolio

A responsive, soft-toned, animated portfolio made with Next.js, TypeScript and Framer Motion.

## Running locally

1. Install Node.js 20.9+.
2. In this directory, run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Highlights

- Floating, auto-cycling 3D project carousel; drag horizontally or use navigation buttons.
- Click a project card to inspect the project detail modal.
- Interactive gradient orb, hover-reactive skill tiles, scroll reveals and animated experience timeline.
- Mobile navigation, accessible keyboard controls and reduced-motion support.
- No personal photographs or external image assets.

## Personalize

- **Project descriptions:** `app/page.tsx` → `projects` array.
- **Career timeline:** `app/page.tsx` → `experience` array.
- **Technology stack:** `app/page.tsx` → `techs` array.
- **Social profile URLs:** `data/site.ts` → `socialProfiles` configuration.
- **Colors, sizing, animation presentation:** `app/globals.css`.
